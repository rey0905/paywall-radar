# 付费陷阱雷达

有些网站是按「漏斗」设计的：先放一个友好的「立即试用」按钮，接着用十页问卷问你的目标，让你上传简历，有时还要填邮箱，直到最后一页才弹出「选择你的方案」，旁边还有一个倒计时。这时用户已经花了二十分钟，也交出了个人信息。这个 skill 的目的是：绝不在没提醒的情况下把用户送进这种网站，并且在自己不注册的前提下，判断出一个网站是不是这种套路。

## 什么算陷阱

如果**用户想做的那件事不付钱就做不了**，这个网站就要被筛掉。如果价格是在用户花了力气之后才出现的（填问卷、传资料、注册账号），就属于**隐藏付费墙**。

免费版能不能用，要按用户真正要做的事来判断。免费版完成不了任务，就当作付费：比如招聘网站只让你看三个职位，简历工具只能导出带水印的 PDF，AI 工具的「免费版」只能预览一次。

公开标价的付费产品不算陷阱，但仍然是付费的。除非用户说过愿意付钱，否则也放进「已筛掉」那一行，并注明价格是公开的。

很多平台是双边的（一边是买家或求职者，一边是卖家或雇主），要看用户站在哪一边。招聘网站通常是雇主付费发布职位，求职者免费浏览和投递。如果求职者这边只是多了一个可选的「Pro 会员」，而免费部分已经能完成任务，那就没问题。

## 基本规矩

定这些规矩是因为：检查一个网站，不应该让用户付出和掉进陷阱一样的代价。

1. 不注册，不填邮箱、姓名、电话、简历，不点「获取权限」「开始试用」或任何购买按钮。为了查一个网站是不是陷阱而把用户的个人信息交给它，就失去了检查的意义。
2. 只读的操作都可以：打开页面、读页面文字、读网站发给每个访客的 JavaScript 代码、修改网址里的步骤编号往后看。
3. 如果要用不涉及个人信息的选项点问卷（比如「你想找什么职位」），必须先得到用户对这个具体网站的明确同意。遇到第一个要填邮箱或注册账号的页面就停下。
4. 只报告看到的事实，并注明日期。不要说某家公司是骗子，而是描述事实（比如「没有价格页；付费页在注册后才出现；每年自动续费 £155.99」），让用户自己判断。

## 检查流程

从成本最低的方法开始，结论一旦清楚就停下。如果是在为推荐列表筛选多个候选网站，先对所有网站做第一步和第二步，只有结论还不清楚的才继续往下查。

**第零步：查名单。** 在 `references/known-sites.md` 里找这个域名。90 天以内的记录可以直接用；更早的要重新核实，因为网站的收费方式会变。

**第一步：查流程外面的公开信息。**
1. 首页：有没有写「免费」，导航栏或页面底部有没有价格页链接？
2. 价格页、常见问题、使用条款。在条款里搜「订阅、自动续费、循环扣款、试用、退款」这些词（英文网站搜 subscription、auto-renew、recurring、trial、refund）。一个从不显示价格的网站却有退款政策，这本身就很说明问题。
3. 如果网站有手机 App，去 App Store 或 Google Play 看它的页面。「App 内购买项目」那一栏会列出真实价格。
4. 用户评价：搜「网站名 reddit」「网站名 trustpilot」「网站名 subscription OR charged OR refund OR paywall」。重点找「填完所有资料才让付钱」和「被意外续费」这类说法。

**第二步：运行检测脚本。** 在这个 skill 的文件夹里运行：

```bash
python3 scripts/probe.py --zh https://example.com
```

它只下载任何访客的浏览器都会下载的东西（网页、网站自己的脚本、公开的政策页），然后报告：有没有价格页链接、有没有写免费、代码里有没有收款服务、有没有付费流程的页面、条款里有没有收费字样。只用 Python 自带的标准库，不需要任何密钥。怎么解读结果见 `references/signals.md`。如果脚本提示页面需要 JavaScript 才能显示，或者抓取失败，有浏览器工具的话就用浏览器打开页面，读渲染后的文字和加载的资源列表。

**第三步：改网址往后看。** 这类流程经常把步骤编号写在网址里，比如 `/journey/2/join/10`、`/onboarding/step-3`、`?step=4`。试试别的数字，尤其是第一步和最后一步，也试试去掉编号的网址。有些网站并不强制你按顺序看页面，所以可能直接跳到付费页。这只是浏览，不算违规操作。

**第四步：亲自试一下用户真正要做的事。** 招聘网站就打开一个职位，看不登录能不能点「申请」；简历工具就看导出是不是免费；AI 工具就看不绑卡能不能真正用一次。这种具体检查一次，比读多少宣传文案都管用。

**第五步：下结论。** 按下面的证据权重和结论分类来判断。

## 怎么权衡证据

在真实招聘网站上测试发现，**几乎每个网站的条款里都有订阅收费条款**，连对求职者真正免费的招聘网站也有。所以条款里有收费字样，单独看说明不了什么。真正能把陷阱和正常网站分开的是下面这些信号。

**强信号（很可能是隐藏付费墙）：**
1. 价格或方案页只在注册流程的最后才出现；
2. 网站哪里都不显示价格，但代码里有付费流程的页面（选方案、付费墙、加价推销、限时优惠、付款处理）；
3. 付费页上有施压手段：倒计时、「五折」首期价、按天显示价格、续费金额写在小字里；
4. 用户评价里有人说填完资料才被要求付费，或者被意外扣款。

**中等信号：**
1. 整个网站找不到价格页链接；
2. 网站从来不说「免费」；
3. 还没让你看到任何产品内容就先问问题（比如没有可以浏览的职位）；
4. 退款保证写得很显眼，却看不到价格。

**反向信号（说明可能没问题）：**
1. 网站明确写了免费，而且第四步确认免费部分能完成任务；
2. 价格页上列出了免费版；
3. 不注册也能浏览核心内容。

**找不到免费的证据，就不要当作免费推荐。** 真正免费的产品都会把「免费」写得很大，因为这是它最好的卖点。一个网站先让用户花力气，又从来不说免费，就得由它来证明自己不收费。

## 结论分类

| 结论 | 意思 | 放在哪里 |
|---|---|---|
| 免费 | 核心任务不花钱就能完成 | 推荐 |
| 免费版够用 | 免费部分能完成任务，另有付费功能 | 推荐，并写明哪些免费、哪些收费 |
| 未确认 | 正反证据都不够 | 单独写一条「未确认，可能收费」，说明还不知道什么 |
| 已筛掉：隐藏付费墙 | 核心任务要付费，而且价格在用户花了力气之后才出现 | 放进「已筛掉」那一行 |
| 已筛掉：付费 | 核心任务要付费，价格公开 | 放进「已筛掉」那一行，除非用户愿意付费 |

## 输出格式

先写推荐的网站，被筛掉的网站集中放在最后一小段。被筛掉的网站仍然要提到，这样用户以后在别处遇到时能认出来。

示例（用户问有没有找远程工作的网站）：

```
**可以用的**
| 网站 | 免费能做到哪一步 |
|---|---|
| Himalayas | 免费浏览和投递；AI 求职工具另收费（每月 29 美元） |
| …… | …… |

**未确认**：Example.io，首页没有价格，没查到投递要不要会员。

**已筛掉**：globalwork.ai，没有价格页，注册问卷走完后才出现付费页（倒计时、五折、按天标价），小字写明每年自动扣 155.99 英镑（2026-10-22 查）。
```

每个网站的证据写一句话就够了。用户想看细节时再展开。

## 用户已经卡在某个网站上时

如果用户贴来一个填到一半的链接，或者刚被某个网站坑了，直接回答这几件事：
1. 有没有免费的方法完成他想做的事？没有就直说。
2. 实际会被扣多少钱？包括自动续费的金额和周期。
3. 如果已经填了资料或绑了卡：建议检查有没有开通订阅并取消，再给网站的联系邮箱发信，要求删除账号和资料。很多网站的条款允许它们广泛使用用户上传的内容，所以值得要求删除。
4. 用同样的流程筛选后，推荐免费的替代网站。
