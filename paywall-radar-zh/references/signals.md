# 怎么解读检测脚本的结果

`scripts/probe.py --zh` 会对每个网址输出一段结果。这份文件解释每一行在查什么、分量有多重，以及到了付费页之后要注意哪些常见的施压手段。

## 逐行解释

| 脚本输出的行 | 查的是什么 | 分量 |
|---|---|---|
| 不用 JS 也能显示页面 | 网页源码里有没有能读的文字。如果没有，说明页面要靠 JavaScript 加载，需要用浏览器打开才能读 | 不算证据，只是告诉你该用什么工具 |
| 页面上有价格页链接 | 页面上有没有「价格」「方案」「会员」这类短链接（比如 `/pricing`、`/plans`、`/premium`） | 「否」是中等警告信号 |
| 明确写了免费 | 页面文字里有没有「免费版」「完全免费」「无需信用卡」这类说法 | 「否」是中等警告信号；「是」是反向信号，但要用第四步确认 |
| 页面上能看到价格 | 页面文字里有没有金额 | 只作参考，职位薪资和雇主发布职位的费用也会被算进来 |
| 代码里的收款服务 | 网页或脚本里有没有引用 Stripe、Paddle、Chargebee、Solidgate 等收款服务 | 单看很弱，因为大多数付费产品都会用；和「没有价格页」同时出现时就很强 |
| 代码里的付费流程信号 | 网站自己的脚本里有没有 `choosePlan`（选方案）、`paywall`（付费墙）、`upsell`（加价推销）、`limitedOffer`（限时优惠）、`payment-process`（付款处理）、`subscriptions/order`（订阅下单）这类页面或组件名 | 网站哪里都不显示价格时，这是**强信号**。只有流程里真的做了付费页，代码里才会有这些名字 |
| 政策页里有收费条款 | 条款、价格页、退款页里有没有自动续费、循环扣款、退款、试用这类字样 | **弱信号**。几乎每个网站都有，包括对用户这一边免费的网站 |

脚本给的是证据，不是结论。一定要问清楚是哪一边在付钱：招聘网站上的「发布一个职位 299 美元」是给雇主的。

## 用真实网站校准（2026-10-22 测试）

| 网站 | 有价格页链接 | 写了免费 | 付费流程代码 | 收费条款 | 实际情况 |
|---|---|---|---|---|---|
| globalwork.ai | 否 | 否 | 6 类（选方案、付款处理、加价推销、限时优惠、订阅接口、价格接口） | 有 | 注册流程最后才出现的隐藏付费墙 |
| himalayas.app | 是 | 是 | 无 | 有 | 求职者免费；AI 工具单独公开标价 |
| weworkremotely.com | 是 | 否 | 无 | 有（可选的求职者 Pro 会员） | 职位免费看；求职者可选付费升级 |
| remoteok.com | 是 | 否 | 无（加载了 Stripe） | 有（会员订阅，写明不提供免费试用） | 能看到职位；没查免费用户能不能投递 |

把陷阱识别出来的组合是：**没有价格页链接，从不说免费，代码里有付费流程**。收费条款四个网站都有。

还有一种套路，单靠脚本识别不出来：**写着免费，但免费刚好做不完你要做的事。** zety.com 写着「基础版免费」，所以脚本会把它算成「写了免费」。但免费版只能下载 TXT 纯文本文件，想要一份能用的 PDF 简历，就得开试用，之后每 4 周自动续费 34.95 新加坡元。只有第四步（检查免费部分能不能完成用户真正的任务）能发现这一点。要留意这几种免费版：能**做**不能**导出**，能**看**不能**申请**，能**预览**不能**使用**。

有些网站（比如 zety.com）会拦截非浏览器的访问，脚本会超时。这不能说明网站有什么问题，换成浏览器工具，直接去读价格页。

## 付费页上的施压手段

如果通过第三步到了付费页，留意下面这些手段。它们说明这个价格是故意设计成让你别细看的。

1. **倒计时**。刷新页面，看它会不会重新开始。
2. **醒目的「五折」首期价**，真正的续费价格只写在小字里。
3. **按天显示价格**（比如每天 0.07 英镑），而不是实际扣款的金额。
4. **按钮旁边的自动续费说明**，比如「不取消的话，每年自动扣款 155.99 英镑」。
5. **用「终身会员」「最受欢迎」做对比**，某个方案存在的主要目的是让另一个显得便宜。
6. **1 美元或 7 天试用**，不取消就自动转成正式订阅。
7. **按「每 4 周」扣款**而不是按月，一年要扣 13 次，不是 12 次。

报告的时候，写真实的扣款金额和周期，不要写「每天多少钱」。

## 证据通常藏在哪里

1. **使用条款里的「订阅」或「付款」那一节**：续费规则写在这里。
2. **退款政策**：能证明这个产品要收钱，哪怕首页从来不提。
3. **网站的 JavaScript 代码**：页面路由表（比如 `/start/payment-process`、`/choose-plan`）和界面文字（比如「订阅已生效，已解锁多少个匹配」）。
4. **应用商店页面**：「App 内购买项目」里有真实价格。
5. **Trustpilot 和 Reddit 上的评价**：「我填完了所有资料，然后……」「试用结束后被扣款」「取消不了」。
